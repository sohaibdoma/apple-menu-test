# Strict Rules (Must Always Follow)

## Rule 1 — Do NOT Change Anything Without Permission

You must **not modify the code unless I explicitly ask you to fix it**.

* Explain the problem

## Rule 2 — Never Guess

If you are **not 100% certain**, do **not guess**.

Instead say:

Then request the missing information such as:

* Another file
* The project structure
* Configuration files
* API routes
